# 用外部配音替换旁白

1. 打开 `冬瓜配音_旁白稿.txt`，全文复制到冬瓜配音（或任何配音工具），只导出人声，不加背景音乐。
2. 留意这几个读音：

   | 句子 | 正确读音 |
   |---|---|
   | 系住有缘人的脚 | 系 jì |
   | 还没拒绝过他的人 / 还特意改成了 | 还 hái |
   | 等着被挑的一方 | 着 zhe，挑 tiāo |

3. 导出 MP3 或 WAV 后运行：`NARRATION="dubbing/旁白.mp3" src/build.sh`
   语音识别会把音频切回每一句旁白，画面、字幕、配乐、音效全部按新配音重新对齐。
