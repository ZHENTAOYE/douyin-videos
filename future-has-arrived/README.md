# 《未来已到达》

横屏科普短片 · 约 3 分 39 秒 · 1920×1080 · 30fps · 纯字幕（暂无配音、配乐与音效）

## 这支片子想做什么

用真实、可核查的数字和尽可能有冲击力的画面，回答一个问题：**人类的科技，究竟走到了哪一步？**
两条主线贯穿全片：

1. **速度**：科技在一个人的一生之内发生了什么样的跃迁（从 1903 年飞 12 秒到 66 年后登月；芯片晶体管 53 年增长约九千万倍；年份越走越快的蒙太奇）。
2. **高度**：今天的技术已经精密/强大到什么地步（几十个原子宽的结构、比太阳表面热 40 倍的等离子体、比宇宙深空还冷的磁体、从宇宙诞生走到今天误差不到 1 秒的钟……）。

结尾落在：**我们总以为未来还很远——其实它已经到了。**

## 视觉方法

- **没有任何素材库视频，也没有 AI 生成图片。** 网络环境无法访问素材站和生成模型，所以全部画面都是代码渲染的：
  - 3D 场景用 moderngl（Mesa llvmpipe 软件 OpenGL 4.5）实时光栅化/光线步进：芯片互连层（7 万个实例化盒体 + 阴影贴图 + 环境反射）、对撞机隧道、托卡马克、DNA、蛋白质、旅行者号模型；
  - 唯一的"真实影像"是地球与月球的卫星纹理（Solar System Scope / NASA），以及 PDB 中的真实蛋白质坐标；
  - 文字与数据图形用 skia 排版：思源黑体（正文）、思源宋体 Black（标题）、Barlow Condensed（数字）。
- 刻意避开"廉价科技感"：没有蓝色 HUD、没有故障特效；每个镜头只讲一件事，用尺度、光和真实数字制造冲击。

## 目录

```
src/
  story.py         全片时间线：场景、字幕卡、里程碑
  cards.py         字幕/数字/章节标/标题的排版与动画
  compose2.py      合成器：场景画面 + 字幕 + 后期（泛光、色调映射、暗角、颗粒）
  gl3d.py          moderngl 小工具：相机、渲染目标、实例化盒体、点、线、网格、全屏着色器
  scene_*.py       各章节画面
  render.py        并行渲染（每个场景一个任务）并拼接
  still2.py        渲染检查用静帧
docs/fact-check.md 事实核查表
output/            成片（mp4 不入库，见下）
```

## 如何渲染

```bash
# 依赖：ffmpeg、Mesa EGL（libegl1 libgl1-mesa-dri libegl-mesa0 libgbm1）、思源字体（fonts-noto-cjk fonts-noto-cjk-extra）
pip install moderngl skia-python opencv-python-headless numpy scipy
# 纹理/字体/PDB 放在 $FHA_WORK/assets（默认 /home/user/work/assets），见 src/config.py
cd src
python3 render.py --workers 3          # 全片 → build/picture.mp4
python3 render.py --only euv,earth     # 只重渲某几个场景，然后：
python3 render.py --concat
```
