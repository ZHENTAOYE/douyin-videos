# 用冬瓜配音（贾老师）替换旁白

1. 打开 `冬瓜配音_旁白稿.txt`，全文复制，粘贴到冬瓜配音的作品里，主播选 **贾老师**。
   - 语速建议先用默认，整片约 5 分钟；想更紧凑可以加快 5%–10%。
   - 不要加背景音乐，只导出人声（配乐由本项目自己合成）。
2. 试听时留意这几个多音字，读错了就用冬瓜配音的“多音字/读音”功能改：

   | 句子 | 正确读音 |
   |---|---|
   | 还写信给罗素挑错 / 还是右边 / 还留在原地 | 还 hái |
   | **还给它换了个名字** | 还 hái（容易被读成 huán） |
   | 可好景不长 | 长 cháng |
   | 就把连线的强弱调一调 | 调 tiáo |
   | 误差传着传着 | 着 zhe |
   | 是个天才少年 | 少 shào |
   | 它猜得没错 | 得 de |

3. 导出 MP3 或 WAV（一个完整文件最好；分段导出也行，按顺序命名）。
4. 把文件发给 Claude，或放进本目录后运行：

   ```bash
   NARRATION="dubbing/旁白.mp3" src/build.sh
   ```

   `src/import_voice.py` 会用语音识别把整段音频切回每一句旁白（实测误差 < 0.05 秒），
   然后画面、字幕、配乐、音效全部按新配音的节奏重新对齐、重新渲染。
   句子之间的停顿由脚本控制，所以你在冬瓜配音里不用手动加停顿。
