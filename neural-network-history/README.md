# 神经网络往事

一支 5 分 24 秒的竖屏科普短片，讲神经网络从 1943 年到 2024 年的 81 年：
一个离家出走的少年写下第一个人工神经元，这个想法两次被判“死刑”，靠几个不肯走的人活下来，最后拿到诺贝尔奖。

**成片在 `output/`，发布文案在 [`publish.md`](publish.md)，带时间码的旁白与逐条事实核查在 [`script.md`](script.md)。**

## 创作思路

- **钩子即结尾**：开场说“你会刷到这条视频，是因为一个神经网络猜你会喜欢它”，结尾请观众点赞，“顺便告诉那个神经网络：它猜得没错”。推荐算法本身就是这个故事的最新一章。
- **一条贯穿的戏剧线**：两次“死刑”（1969、1990s）用同一枚红色印章，冬天用同一场雪；“回响”在结尾兑现，1982 年的霍普菲尔德、2012 年的伊利亚都在后面被点名回收。
- **档案馆视觉**：深色底、暖纸色档案卡、琥珀色的“放电”神经元。每个人物是一张编号档案卡，顶部年代轴从 1943 走到 2024，两段寒冬在轴上留下冰蓝色。
- **能演示的就演示**：开关神经元、逻辑门、异或画不出直线、反向传播的“层层追责”、卷积扫描、AlexNet 的错误率柱状图都是动画。感知机那段是真的跑了 50 次感知机学习，画面上的权重图就是实际训练出来的权重。
- **说准**：每个年份、数字、引语都核对过（见 `script.md`）。传闻类细节（图书馆三天、卧室显卡、投稿被拒）一律用“据说”，并在画面上标注。

## 全部由代码生成

| 环节 | 做法 |
|---|---|
| 旁白 | 离线 TTS：Kokoro v1.1-zh（sherpa-onnx），男声 #62。每句合成后用 SenseVoice 语音识别回听，发音不达标就换语速重合成；ChatGPT、ImageNet、“好景不长”等易错读音单独校正 |
| 字幕 | 按标点切块，时间吸附到音频里真实的停顿上；关键词高亮 |
| 画面 | Node + `@napi-rs/canvas` 逐帧绘制 1080×1920@30fps，20 个场景的每个动作都锚定在旁白时间点上；4 进程并行渲染 |
| 配乐 | numpy/scipy 合成的原创配乐：钢琴、拨弦、Pad、鼓都是算出来的，随剧情分 15 段（神秘 → 希望 → 寒冬 → 复苏 → 翻盘 → 加速 → 回响），贯穿一个四音动机 A–C–E–D |
| 音效 | 200 多个音效（印章、纸张、神经元放电、竞拍木槌、围棋落子……）由渲染器按画面事件导出时间点后合成 |
| 混音 | 旁白驱动的音乐闪避（ducking），两遍 loudnorm 到 -14 LUFS / -1.5 dBTP；成片又用语音识别回听，确认配乐没有盖住人声 |

## 重新生成

```bash
cd neural-network-history
npm install
pip install sherpa-onnx numpy scipy
src/fetch_assets.sh     # 字体与离线语音模型（约 1 GB，来自 GitHub Releases，不入库）
src/build.sh            # → output/
```

改 `src/script.py` 里的一句话或一个停顿，整部片子（画面、字幕、配乐、音效）都会自动重新对齐。

预览单帧：`cd src/render && node main.js --still 12.5,40`（输出到 `build/stills/`）。

